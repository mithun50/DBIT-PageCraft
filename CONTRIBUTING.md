# Contributing to DBIT PageCraft

Thanks for your interest in contributing! Here's how you can help.

## Getting Started

1. Fork the repository
2. Clone your fork:
   ```bash
   git clone https://github.com/YOUR-USERNAME/DBIT-PageCraft.git
   cd DBIT-PageCraft
   ```
3. Start a local server:
   ```bash
   npx serve
   ```
4. Open `http://localhost:3000` in your browser

## How to Contribute

### Reporting Bugs

- Open an issue with a clear title and description
- Include steps to reproduce the bug
- Add screenshots if applicable

### Suggesting Features

- Open an issue with the `enhancement` label
- Describe the feature and why it would be useful

### Submitting Changes

1. Create a new branch: `git checkout -b feature/your-feature`
2. Make your changes
3. Test locally to ensure nothing breaks
4. Commit with a clear message: `git commit -m "feat: add your feature"`
5. Push and open a Pull Request

## Guidelines

- Keep it simple - no build tools or frameworks needed
- Test on both desktop and mobile
- Maintain the existing code style (vanilla JS, no dependencies beyond CDN libs)
- Ensure PDF output quality is not affected by UI changes
